## **Troubleshooting**

### **"Streamlit app won't deploy"**
- Check requirements.txt has all packages
- Check app.py runs locally: `streamlit run app.py`
- Check file paths

### **"Landing page link broken"**
- Verify Streamlit URL is correct
- Test each button individually
- Check WhatsApp number format

### **"No responses to emails"**
- Check spam folder
- Try different subject lines
- Move to phone calls/WhatsApp instead

### **"People want feature X"**
- Add it to roadmap but DON'T build yet
- Focus on getting 5 paying customers first
- Then iterate based on feedback
